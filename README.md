# AquaCozy content

Music and radio stations for [AquaCozy](https://play.google.com/store/apps/details?id=com.ugurgulay.aquacozy),
published on GitHub Pages so the game can get new music without an app update.

- `music/catalog.json`: what the in-game radio reads. It lists the Reef FM
  songs and the extra procedural stations.
- `music/tracks/`: the songs, as MP3.
- `music/CREDITS.md`: every song's author, licence and source.

Every song is the work of its author and is used under the licence named
in `music/CREDITS.md`. Only CC0 and CC BY songs are published here. No
other licence in this repository covers them.

The catalog is generated by `tools/music/build_catalog.py` in the game's
repository; edit `tools/music/sources.json` there, not the catalog.
